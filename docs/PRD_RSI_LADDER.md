| 관련 | [`PRD_RWM_BOWL.md`](./PRD_RWM_BOWL.md) (주봉 리샘플 RSI, 20/60 이평, 오버나잇·글로벌 트레일 예외) |
| 화면 목업 | `/ladder` → [`static/ladder.html`](../static/ladder.html) (샘플 데이터, 백엔드 미연동) |

긴 하락으로 RSI 가 바닥을 여러 번 찍은 종목이 20일선이 60일선을 뚫고 올라오는 날 1차로 산다. 그 뒤 **15:05 현재가가 직전 매수가보다 5% 낮으면 한 칸씩 더 산다** (최대 10칸). 수익 중에 20일선을 깨면 절반을 팔고, 수익이 +15% 를 한 번이라도 넘으면 10일선 → 15일선 → 20일선 순서로 이탈할 때마다 나눠 판다. 모든 판정은 **하루 1번, 15:05 현재가(종가 대용)** 로 한다.

기존 전략과 다른 점: 기존 전략은 하루~수일 단기 매매이고 손절이 짧다. 본 전략은 몇 주~몇 달 보유를 전제로 하락을 추가 매수 기회로 본다. 그래서 기존 글로벌 손절·트레일링·장 마감 청산이 이 포지션에 걸리면 안 된다 (§6.3).

## 0. 컨셉

### 0.1 한눈에

```text
[1차 진입]  (주봉 RSI ≤ 30 발생  OR  일봉 최근 120거래일 RSI ≤ 30 저점 3회 이상)
            AND  20일선이 60일선 상향 돌파(GC)
            → GC 당일 15:05 매수.   또는 사용자가 화면에서 수동 1차 매수

[추가 매수] 15:05 현재가 ≤ 직전 체결가 × 0.95  → 매수 (2차 ~ 10차, 하루 최대 1차수)
            10차 이후 더 떨어지면 → 자동 매수 없음, 사용자가 수동 판단 (알림)

[매도]      ┌ 익절 무장 전 (최고 수익률 < +15%)
            │   현재가 > 평단(수익 중) AND 현재가 < 20일선  → 보유량 50% 매도 (1회)
            │   손실 중 20일선 이탈은 무시 (물타기 구간)
            └ 익절 무장 후 (평단 대비 +15% 한 번이라도 도달)
                현재가 < 10일선 → 50%  →  < 15일선 → 25%  →  < 20일선 → 나머지 25%

모든 판정: 매 거래일 15:05 현재가 1회 (이하 "종가"는 15:05 현재가를 뜻함)
```

### 0.2 사다리 예시 (1차 10,000원, 직전 체결가 −5%)

```text
  10,000 ● 1차  GC 당일 종가                         평단 10,000
   9,500 ● 2차  종가 ≤ 9,500                          평단  9,750
   9,020 ● 3차  종가 ≤ 9,025 → 호가 내림 9,020        평단  9,508
   8,560 ○ 4차  ← 다음 매수가
   ...
   6,290 ○ 10차 (1차 대비 약 −37%)
```

| 용어 | 뜻 |
|---|---|
| 사다리 | 한 종목의 1~10차 매수 계획 + 매도 단계 전체. 종목당 동시에 1개 |
| 트리거가 | 다음 차수 매수 가격 = 직전 체결가 × 0.95 (호가 내림) |
| 종가 판정 | 15:05 현재가를 종가로 보고 조건 판정 → 바로 지정가(현재가) 주문 (§3.3 주문 흐름) |
| 익절 무장 | 평단 대비 수익률이 한 번이라도 +15% 이상 (종가 기준) → 단계 익절 규칙으로 전환 |
| 기준수량 | 매도 % 를 계산하는 수량. 해당 규칙이 처음 발동하는 시점의 보유 수량 |

### 0.3 원칙

1. **바닥 확인(RSI) + 추세 전환(GC) 이 같이 있어야 자동으로 산다.** 둘 다 없으면 사람이 판단해서 수동으로 산다.
2. **장중 꼬리에 반응하지 않는다.** 매수·매도 모두 장 마감 직전 현재가로만 판정한다.
3. **한 번에 다 사지 않고, 한 번에 다 팔지 않는다.** 매수 10회, 매도 2~3회로 나눈다.
4. **10차를 다 채우면 기계는 멈춘다.** 그 뒤는 사람이 판단한다 (무한 물타기 금지).

## 1. 파이프라인

```text
[사용자] 화면에서 종목 등록 (총 투자금, 간격 −5%, 최대 10차, 진입 방식 자동/수동)
     │
     ├─ 수동 ─▶ 즉시(또는 지정 시점) 1차 매수 → ACTIVE
     ▼
[RSI_WAIT] 매일 장 마감 판정
     │  ① 주봉 RSI 저점 / ② 일봉 120일 RSI 저점 횟수 / ③ 20/60 GC  — 화면에 진행 상황 표시
     │  (①or②) and ③ → 1차 종가 매수
     ▼
[ACTIVE] 매 거래일 15:05 판정 (현재가 1회 조회, 실시간 감시 불필요)
     │  매도 규칙 먼저 → 그다음 추가 매수
     │  종가 ≤ 트리거가 → N차 종가 매수 → 평단 재계산 → 다음 트리거가
     │  10차 체결 → [FULL] 자동 매수 중지, 매도 규칙만, "수동 판단" 알림
     ▼
[매도 규칙] 20일선 이탈 50% / 익절 무장 후 10·15·20일선 단계 매도
     │  보유 0 → [DONE]
```

장중(09:00~15:05)에는 **표시만** 한다: 현재가, 다음 트리거까지 거리, 이평까지 거리. 텔레그램 "오늘 판정 예상" 알림은 옵션 (14:50).

## 3. 규칙 상세

### 3.1 1차 진입 — 자동

```text
[R1 주봉 RSI 저점]
  최근 weekly_lookback_weeks(26주 ≈ 120거래일) 안에 확정 주봉 RSI(14) ≤ rsi_weekly(30) 인 주가 1개 이상
  주봉 = 일봉 리샘플 (ISO 주, 주 마지막 거래일 종가). 진행 중 주봉은 판정에 쓰지 않음

[R2 일봉 RSI 저점 반복]
  최근 daily_lookback(120거래일) 안에서 일봉 RSI(14) ≤ rsi_daily(30) "저점 구간" 횟수 ≥ daily_low_count(3)
  저점 구간 1회 = RSI 가 30 이하로 들어간 날부터 rsi_reset(35) 위로 회복할 때까지
                  (29 → 31 → 29 처럼 30 근처에서 출렁이는 것을 여러 번으로 세지 않기 위함)

[G 20/60 골든크로스]
  MA20[t−1] ≤ MA60[t−1]  AND  MA20[t] > MA60[t]          (t = 오늘, 현재가를 종가로 넣어 계산)
  GC 당일을 놓친 경우(서버 중단 등) gc_fresh_days(3) 거래일 안이면 인정

진입 조건 = (R1 OR R2) AND G           → 15:05 판정, 1차 매수 (사용자 확정 C2)
RSI 저점(R1/R2)은 GC 날 기준 과거 120거래일 안에만 있으면 된다 (같은 날일 필요 없음)
```

| 예 | R1 주봉 | R2 일봉 저점 횟수 | G (GC) | 결과 |
|---|---|---|---|---|
| A | ✓ (8주 전 주봉 RSI 27) | 1회 | 오늘 GC | **매수** |
| B | ✗ (주봉 최저 34) | 3회 | 오늘 GC | **매수** |
| C | ✗ | 2회 | 오늘 GC | 대기 (R 미충족) |
| D | ✓ | 4회 | GC 없음 (이격 1.5%) | 대기 — 화면에 "GC 임박" 표시 |

- RSI 는 기존 `utils/auto_trade_engine.py` `compute_rsi_series` (Wilder) 재사용. 주봉도 같은 함수.
- 일봉 ≥ 200봉 필요 (MA60 + RSI 수렴 + 120일 구간). 부족하면 `INSUFFICIENT_BARS` → 수동 매수만 가능.
- `rsi_wait_days`(기본 0 = 무기한): 등록 후 N거래일 동안 조건 미충족이면 자동 만료.

### 3.2 1차 진입 — 수동

- 화면 "1차 수동 매수" 버튼. 기본은 **즉시 현재가 지정가**. 옵션: "오늘 15:05 판정 때 매수" 예약.
- 등록 시 진입 방식을 `manual` 로 고르면 등록 직후 1차 매수 확인 창을 띄운다.
- 자동 대기(`RSI_WAIT`) 중에도 언제든 수동 1차 매수 가능 → 이후는 자동 사다리.

### 3.3 추가 매수 (2~10차) — 15:05 현재가 기준 (사용자 확정 C3)

```text
판정 시각   : judge_time(15:05) — 이 시각 현재가를 종가 대용으로 사용
트리거가    : next_trigger = tick_floor( 직전 차수 체결가 × (1 − step_pct(5)/100) )
조건        : 15:05 현재가 ≤ next_trigger
하루 최대   : 1차수 (판정이 하루 1번이라 자연히 1차수)
```

**주문 흐름 (매수·매도 공통)**

```text
15:05  판정 → 매수: 매수 신호 생성 → 기존 매수 실행기가 자동매매 설정의 주문 방식(기본 시장가)으로 주문
             매도: 계획에 "매도 대기" 기록 → 손절 감시 루프가 정규장에 지정 수량 매도
체결   PositionBuyFill / SellOrder 로 10초마다 대조 → 차수·매도 단계 확정
실패   매수 신호 FAILED → 그날 판정분 취소, 다음 거래일 15:05 재판정 (소급 없음)
```

(v0.4.0) 15:10 정정 · 15:15 취소 흐름은 넣지 않았다. 기존 매수 실행기의 주문 경로를 그대로 써서 시장가 체결을 기본으로 한다.

- 장중에 −5% 아래로 꼬리를 달았다가 15:05 에 회복해 있으면 **사지 않는다.**
- 15:05 현재가가 트리거보다 훨씬 낮으면(예: −12%), 그날 1차수만 사고 그 체결가 기준으로 다음 트리거를 다시 잡는다.
- 15:05 이후 종가까지의 움직임은 반영하지 않는다. 체결가가 곧 다음 트리거의 기준.

### 3.4 차수별 금액

```text
차수당 금액 = total_budget / max_steps (균등)
qty(N)     = floor(차수당 금액 / 주문가)      # 0주면 SKIP_QTY_ZERO
```

계좌 주문가능금액 부족 시 매수 보류 + 알림 (`INSUFFICIENT_CASH`).

### 3.5 10차 이후

- 10차 체결 → 상태 `FULL`. 자동 추가 매수 없음.
- 텔레그램 1회: "10차 소진 — 이후 추가 매수/손절은 수동 판단". 이후 종가가 10차 체결가 대비 −5% 씩 더 내려갈 때마다 참고 알림 (매수는 안 함, 옵션 `full_alert_step_pct`).
- 매도 규칙(§3.6)은 FULL 에서도 그대로 작동.
- 화면에서 "수동 추가 매수"(11차, 12차…) 가능. 수동 차수도 평단 계산에 포함.

### 3.6 매도

모든 판정은 15:05 현재가 기준. MA 는 오늘 15:05 현재가를 오늘 종가로 넣어 계산한다.

```text
수익률 pnl_pct   = (현재가 / 평단 − 1) × 100
최고 수익률 peak = 보유 이후 매일 15:05 판정 시 pnl_pct 최댓값 (저장)
익절 무장 armed  = peak ≥ tp_arm_pct(15)

[무장 전]  S0: 현재가 > 평단 (수익 중)  AND  현재가 < MA20
              → 보유량의 50% 매도 (사이클당 1회, 사용자 확정 C1)
              손실 중 MA20 이탈은 매도 안 함 — 물타기 구간이므로 −5% 추가 매수 규칙만 작동
[무장 후]  S1: 종가 < MA10  → 기준수량의 50% 매도
           S2: 종가 < MA15  → 기준수량의 25% 매도      (S1 이후에만)
           S3: 종가 < MA20  → 남은 수량 전량           (S2 이후에만)
           기준수량 = 무장 후 첫 매도(S1) 직전 보유 수량
```

| 상황 | 처리 |
|---|---|
| 무장 후 하루 만에 종가가 MA10·MA15·MA20 모두 아래 | S1·S2·S3 같은 날 모두 발동 → 전량 |
| S1 발동 후 다시 상승해 MA10 위로 복귀 | S1 은 이미 끝, 다음은 S2(MA15 이탈) 대기. 되사지 않음 |
| 평단 9,275, 현재가 9,100 (손실), MA20 9,400 아래 | S0 없음. 트리거 이하면 추가 매수 |
| 평단 9,275, 현재가 9,600 (+3.5%), MA20 9,700 아래 | S0 발동 → 50% 매도 |
| 무장 전 S0 으로 50% 판 뒤 +15% 도달 | 무장 → 남은 수량 기준 S1/S2/S3 |
| 무장 후에는 S0 미적용 | S3(MA20 이탈) 이 대신함 |
| 매도 비율 수량 계산 | `floor`, 최소 1주. 마지막 단계는 남은 수량 전부 |

**매도 후 추가 매수:**
- 익절 무장 후 매도(S1~S3)가 한 번이라도 나가면 → 상태 `EXITING`, **추가 매수 중지**.
- 무장 전 S0(수익 중 20일선 이탈 50%) 후 → **사다리 계속** (다음 트리거 = 직전 매수 체결가 × 0.95, 그대로). S0 은 평단 위에서만 나가고 추가 매수는 직전 체결가 −5% 아래에서만 나가므로, 같은 날 둘 다 성립하는 경우는 사실상 없다. 성립하면 매도만.

### 3.7 상태머신

```text
RSI_WAIT ──(자동 조건 or 수동 매수)──▶ ACTIVE ──(10차)──▶ FULL
                                         │  │                 │
                                         │  └─(S1~S3 매도)─▶ EXITING
                                         ▼                    │
                                       PAUSED (매수 중지)      │
            (보유 0 / 수동 종료) ──────────────────────────▶ DONE
```

| 상태 | 배지 | 추가 매수 | 매도 규칙 |
|---|---|---|---|
| `RSI_WAIT` | 진입 대기 | 1차 조건만 | — |
| `ACTIVE` | 감시중 | ✓ | ✓ |
| `FULL` | 10차·수동판단 | ✗ (수동만) | ✓ |
| `EXITING` | 익절 진행 | ✗ | ✓ |
| `PAUSED` | 일시정지 | ✗ | ✗ (자동 판정 전체 중지, 수동 매도는 가능) |
| `DONE` | 종료 | ✗ | ✗ |

## 6. 시스템 연동

### 6.1 판정 스케줄

| 시각 | 작업 |
|---|---|
| 15:05~15:20 | 하루 1회. 모든 ACTIVE/FULL/EXITING/RSI_WAIT 사다리: 현재가 + 확정 일봉으로 MA·RSI 계산 → 매도 → (매도 없으면) 매수 → 진입 판정. 서버가 15:05 에 꺼져 있었어도 15:20 전에 켜지면 그때 판정 |
| 10초마다 | 체결 대조 (매수 체결 → 차수 확정, 매도 체결/실패 → 단계 확정/되돌림, 보유 0 → DONE) |
| 15:40 | 텔레그램 일일 요약 |
| 화면 | 30초마다 상태 조회 (현재가·지표 60초 캐시). 주문 없음 |

- 사다리 ≤ 10 종목이라 15:05 에 일봉·현재가 조회 10~20건 → API 제한 여유.
- `peak_pnl_pct`·무장 여부는 15:05 판정값으로 갱신 (판정과 같은 가격을 써야 규칙이 일관됨).
- 일봉은 전일까지 캐시 + 오늘 현재가를 마지막 봉으로 붙여 MA/RSI 계산.

### 6.2 주문

- 매수: `managers/buy_order_executor.py` 에 `rsi_ladder` 분기. `suggested_qty` 를 그대로 주문(시장가 여유 버퍼로 줄이지 않음, 주문가능금액만 상한). 레거시 등락률·가격상한·진입 게이트·전역 동시보유 한도 미적용. 매수 가능 시간 09:00~15:20, 장마감 청산 시각 이후 신규매수 금지 규칙 제외.
- 매도: `StopLossManager._monitor_ladder_exit` 가 `pending_sell` 을 읽어 `_execute_sell_order(quantity=n)` 로 부분/전량 매도.
- 체결 대기(`pending_buy` / `pending_sell`) 중에는 같은 사다리 추가 주문 금지.
- 다른 전략이 보유 중인 종목은 등록·매수 거부 (같은 종목 포지션이 합쳐지는 것 방지).
- 부분매도 체결 확정 버그 수정: 2번째 부분매도부터 매도수량이 0으로 계산돼 ORDERED 에 묶이던 문제 → 계좌 수량 감소분 기준(주문수량 상한)으로 변경. 분할매수는 매도 직전 보유수량(`pre_hold`)을 기준으로 판정.

### 6.3 기존 손절/청산에서 제외 (중요)

| 기존 장치 | 처리 |
|---|---|
| `StopLossManager` 글로벌 손절률 / 트레일링 / `take_profit_rate` | `strategy_key == "rsi_ladder"` 포지션 **제외**. 사다리 매도 규칙만 |
| 장 마감 일괄 청산(EOD flatten) | 제외 (오버나잇 필수) |
| 시장 리스크 게이트 | (v0.4.0) 1차 포함 미적용 — 급락장이 곧 매수 구간이고 종목·예산을 사용자가 직접 지정 |

## 10. 수락 기준

**진입**
- [ ] 주봉 RSI 27 (8주 전) + 오늘 20/60 GC → 1차 매수
- [ ] 주봉 최저 34, 일봉 120일 내 저점 구간 3회 + GC → 1차 매수
- [ ] 일봉 저점 구간 2회 + GC → 대기
- [ ] RSI 29 → 31 → 29 (35 회복 없음) → 저점 1회로 집계
- [ ] R1 충족, GC 없음 → 대기, 화면에 MA20/MA60 이격 표시
- [ ] GC 3거래일 전 + R 충족 + 서버가 GC 당일 다운 → 오늘 매수. 4거래일째 → 대기
- [ ] 수동 1차 매수 → 즉시 ACTIVE, 2차 트리거 = 체결가 × 0.95

**추가 매수**
- [ ] 1차 10,000 → 2차 트리거 9,500. 장중 저가 9,300, 15:05 현재가 9,600 → 매수 없음
- [ ] 15:05 현재가 9,480 → 지정가 2차 매수, 3차 트리거 = 체결가 × 0.95 (호가 내림)
- [ ] 15:05 매수 신호가 실행기에서 실패 → 그날 판정분 취소, 다음 거래일 재판정
- [ ] 15:05 현재가 8,700 (−13%) → 그날 2차만
- [ ] 10차 체결 → FULL, 알림 1회, 이후 자동 매수 없음. 수동 11차 매수 가능

**매도**
- [ ] 무장 전, 수익 중 현재가 < MA20 → 50% 매도 (S0), 이후 다시 MA20 이탈해도 추가 S0 없음
- [ ] 무장 전, 손실 중 현재가 < MA20 → 매도 없음
- [ ] 최고 +15.2% 도달 → 무장. 이후 종가 < MA10 → 기준수량 50%
- [ ] S1 후 종가 < MA15 → 25%, 이어서 < MA20 → 나머지 전량 → DONE
- [ ] 무장 후 하루에 MA10·15·20 모두 이탈 → 전량
- [ ] S1 이후 상태 EXITING, 종가 −5% 하락해도 추가 매수 없음
- [ ] 글로벌 손절 −3% 설정에서도 사다리 포지션 −20% 미매도, EOD 청산 ON 이어도 유지

**공통**
- [ ] 서버 재시작 후 상태·트리거·단계 동일
- [ ] mock 계좌에서 실주문 어댑터 미호출
