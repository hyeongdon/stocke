> **상태**: Implemented Phase 0–2 (엔진·UI·분할진입/익절) — 조건식·수치 운영 확정 대기  
> **작성일**: 2026-07-25  
> **구현일**: 2026-07-25  
> **대상 시스템**: stocke 자동매매 (`AutoTradeScanner` → `BuyOrderExecutor` → `StopLossManager`)  
> **관련 코드**: `utils/ymgp_engine.py`, `utils/auto_trade_engine.py`, `managers/auto_trade_scanner.py`, `managers/buy_order_executor.py`, `managers/stop_loss_manager.py`, `core/models.py`, `static/dashboard.js`

> **차별점**: 과매도 돌파(`breakout`)는 “과매도 이력 → 고점 돌파” 1샷. 역매공파는 **역배열 바닥에서 회복 신호가 확인된 자리만** 다단계로 공략.

## 0. 한 줄 결론 · 개발 가능 여부

**개발 가능하다.**  
이미 있는 **전략 프로필 + 게이트 패키지 + `strategy_key` + 피라미딩 추가매수 + 전략별 청산** 골격 위에,  
**일봉 상태 머신**(필터 → 준비 → 매집/공구리 → 진입 → 관리)과 **장기 이평(60/112/224/448)** 판정을 올리면 된다.

| 판정 | 내용 |
|------|------|
| **가능** | 진입·손절·익절 규칙을 상태별로 고정하는 방식은 코드베이스와 잘 맞음 |
| **핵심 추가분** | 종목별 `ymgp_stage` 상태 저장, 일봉 MA·박스권·매집봉 판정기, 분할 익절, 손절 후 재진입 락 |
| **비범위(1차)** | 전종목 일봉 전수 스캔으로 유니버스 구성 (API 비용) — **조건식 유니버스 + 소수 후보 일봉 검증** 권장 |
| **과매도 돌파와 관계** | **별도 4번째 전략**. `breakout`을 덮어쓰지 않음 |

```
역배열에서 “떨어지는 칼”이 아니라
  바닥 다지기 → 매집봉/공구리 → 기준선 돌파 또는 눌림 재매수
만 잡는다.
```

## 1. 배경 · 문제

### 1.1 전략 정의 (제품 언어)

역매공파는 다음을 **한 시퀀스**로 본다.

| 단계 | 의미 | 자동매매에서의 역할 |
|------|------|---------------------|
| **역** | 장기 이평 역배열 (하락 구조) | 필터 — 후보 자격 |
| **매** | 매집봉 (거래량↑ + 양봉 마감 품질) | 준비→진입 트리거 |
| **공** | 공구리 (박스권 바닥 다지기, 지지 흔적) | 준비완료 판정 |
| **파** | 기준봉 고점/전일고 돌파 또는 눌림 후 재돌파 | 실제 매수 |

실전에서 함께 보는 축:

- **60일선 안착**, 매집봉, **파란점선/볼린저 상단 근접**, **112일선 회복**
- 목표는 단기 **224일선**, 장기 **448일선** 등 **다단계 분할 익절**
- 손절은 **기준봉 저점** 또는 **60/112일선 종가 이탈**

### 1.2 왜 기존 전략으로 부족한가

| 기존 | 한계 |
|------|------|
| `legacy_momentum` | 대금·당일 품질 중심. 역배열 바닥·장기 MA 회복을 전제로 하지 않음 |
| `sangtta` | 장초·상한가 근접. 보유·리스크 프로파일이 반대 |
| `breakout` (과매도 돌파) | RSI/조건식 과매도 → **고점 돌파 1회**에 가깝다. **상태 전이·공구리·2차 눌림매수·224/448 분할익절·손절 후 재진입 금지**가 없음 |

→ 조건을 OR로 legacy/breakout에 끼우면 “칼날 줍기”와 “회복 자리”가 섞인다.  
→ **네 번째 전략 프로필**이 필요하다.

### 1.3 지금 코드가 이미 주는 것

| 자산 | 역매공파에 쓰는 법 |
|------|-------------------|
| 게이트 패키지 (`evaluate_gate_pack`) | `yeokmaegongpa` (또는 `ymgp`) 패키지 추가 |
| `Position.strategy_key` | `ymgp` 태그로 청산·검증 분리 |
| 피라미딩 (`is_add_buy`, `_scan_pyramiding_adds`) | 1차 돌파 → 2차 눌림 추가매수에 재사용 |
| 조건식 유니버스 (`*_condition_names`) | 역배열·횡보 후보를 HTS에서 축소 |
| HARD/SOFT 청산 패턴 | 기준선 이탈에 재사용 |
| 검증 체크리스트 | 단계·매집봉·공구리·돌파 항목 추가 |

## 2. 제품 목표

### 2.1 Goals

1. **상태 머신**으로 후보를 관리한다: `FILTERED` → `READY` → `ARMED` → `ENTERED` → `MANAGING` → (`STOPPED` / `DONE`).
2. **회복 신호가 확인된 종목만** 매수한다 (역배열 그 자체가 매수 신호가 아님).
3. **1차(돌파) + 2차(눌림)** 분할 진입, **저항/224/448** 분할 익절, **기준선 이탈** 즉시 손절을 end-to-end로 고정한다.
4. **손절 후 즉시 재매수 금지** — 매집봉·박스권 재형성 후에만 재공략.
5. legacy / sangtta / breakout **회귀 없음** (`use_ymgp=false` 시 기존과 동일).

### 2.2 Non-goals (1차)

- 전종목·대금 TopN 일봉 전수 스캔으로 유니버스 구성 (API rate limit)
- “완벽한 바닥” 예측, 테마 NLP
- 틱/호가 HFT
- 완전 자동 백테스트 엔진 (별도 플랜)
- 과매도 돌파(`breakout`) 설정을 역매공파로 교체

### 2.3 성공 지표 (초안)

| 지표 | 1차 목표 |
|------|----------|
| 매수 시그널의 `ymgp_stage` | 100% `ARMED` 이상에서만 발생 |
| “역배열만 있고 매집/공구리 없음” 매수 | 0 |
| 손절 후 쿨다운 내 재진입 | 0 |
| `strategy_key=ymgp` 라운드트립 | 진입→분할익절/손절 로그 일관 |
| 기존 전략 회귀 | `use_ymgp=False` 스냅샷 동일 |

## 3. 현재 → 목표 그림

```
[유니버스: ymgp_condition_names 조건식 통과분]
        │
        ▼  일봉 상태 평가 (소수 후보만 REST/차트)
┌───────────────────────────────────────────┐
│ FILTERED  역배열 + 변동성/거래량 살아 있음     │
│ READY     박스권 + 60/112 근처 지지           │
│ ARMED     매집봉 확인 (+ 공구리 1개 이상)      │
│ ENTERED   1차 돌파 매수 / 2차 눌림 추가        │
│ MANAGING  손절·분할익절·트레일                 │
│ STOPPED   손절 → 재진입 락 (쿨다운/재형성 대기) │
└───────────────────────────────────────────┘
        │
        ▼
신호(strategy=ymgp) → 주문 → Position.strategy_key=ymgp
        │
        ▼
청산: 기준선/기준봉 이탈 → 고정손절 → 224/448 분할익절 → (선택)트레일
```

**방식**: 상따·과매도 PRD와 동일하게 **방식 B (게이트 패키지 + 전략 태그)**.  
조건만 OR로 늘리는 방식 A는 비추천.

## 4. 상태 머신 · 조건식 설계

### 4.1 상태 정의

| `ymgp_stage` | 의미 | 자동 주문 |
|--------------|------|-----------|
| `NONE` | 미관심 / 필터 탈락 | 없음 |
| `FILTERED` | 역배열·활력 후보 | 없음 (관측만) |
| `READY` | 바닥 박스 + 지지 흔적 | 없음 (관심) |
| `ARMED` | 매집봉(+공구리) 확인, 돌파 대기 | 없음 |
| `ENTERED_1` | 1차 진입 완료 | 보유·2차 대기 |
| `ENTERED_2` | 2차(눌림)까지 완료 | 보유 |
| `MANAGING` | 익절 단계 진행 중 | 분할 매도만 |
| `STOPPED` | 손절 청산 | **재진입 금지** (락) |
| `DONE` | 익절 완료 / 전략 종료 | 없음 |

전이만 허용 (스킵 진입 금지):

```
NONE → FILTERED → READY → ARMED → ENTERED_1 → [ENTERED_2] → MANAGING → DONE
                                              ↘ STOPPED ──(재형성)──► READY|ARMED
```

### 4.2 필터 조건 (`FILTERED`)

| # | 조건 | 초안 정의 | 데이터 |
|---|------|-----------|--------|
| F1 | 역배열 | `MA120 < MA240 < MA480` **또는** 설정 가능 3선 (예: 60/112/224)이 역배열 | 일봉 |
| F2 | 급락 후 횡보 | 최근 `drop_lookback`(예: 60일) 내 고점 대비 `drop_pct`(예: ≤ −20%) 후, 최근 `box_days`(10~20) 횡보 | 일봉 |
| F3 | 거래량 조짐 | 최근 박스 구간 평균 대비 직근 거래량이 **급감 후 증가** (예: 5일 평균 ≥ 박스평균 × 1.2) | 일봉 |
| F4 | 활력 | 최근 N일 ATR% 또는 고저폭이 하한 이상 (죽은 종목 제외) | 일봉 |
| F5 | 공통 제외 | ETF/ETN·스팩·우선주·관리·투자주의 | 기존 스크리너 |

**유니버스(권장)**: HTS 조건식으로 F1~F2 골격을 줄이고, 서버는 통과분에만 F3~F5 + 이후 단계 계산.

### 4.3 바닥 확인 · 준비완료 (`READY`)

| # | 조건 | 초안 정의 |
|---|------|-----------|
| R1 | 박스권 | 최근 `box_days`(기본 15) 고저폭 ≤ 구간 중간가 × `box_width_pct`(예: 12%) |
| R2 | 이중 저점 | 최근 N일 저점이 **비슷한 수준(±`pivot_tol_pct`)** 으로 **2회 이상** |
| R3 | 지지 흔적 | 종가가 **60일선 또는 112일선**의 ±`ma_near_pct`(예: 3%) 이내에서 지지(저점 ≥ MA×(1−ε) 후 반등) |
| R4 | (선택) 장대음 후 반등 | 장대음봉 이후 양봉/반등봉 1개 이상 |

→ `READY` = R1∧R2∧(R3∨R4). 매수 아님.

### 4.4 매집봉 · 공구리 (`ARMED`)

**매집봉 (M)**

| # | 조건 | 초안 |
|---|------|------|
| M1 | 거래량 | 당일(또는 직전 확정 일봉) 거래량 ≥ 최근 20일 평균 × `accum_vol_mult`(기본 **2.0**) |
| M2 | 양봉 품질 | 종가 ≥ 시가 **그리고** 종가 ≥ (고+저)/2 |
| M3 | (선택) 20일선 | 종가 ≥ MA20 |

**공구리 (G)** — “20/60/112 중 **최소 1개** 회복 또는 근접”

| # | 조건 | 초안 |
|---|------|------|
| G1 | 회복 | 종가 ≥ MA20 또는 MA60 또는 MA112 |
| G2 | 근접 | 종가가 위 MA 중 하나와 거리 ≤ `ma_near_pct` |
| G3 | (선택) 볼린저/파란점선 | 고가 또는 종가가 볼린저 상단(또는 대체 기준선) **근접**(≤ `bb_near_pct`) — 1차는 옵션 |

→ `ARMED` = (`READY`) ∧ **M** ∧ (**G1∨G2**) ∧ (선택 G3).  
매집봉 일자를 **기준봉(reference bar)** 으로 저장: `ref_high`, `ref_low`, `ref_open`, `ref_date`.

### 4.5 진입 조건 (`ENTERED_1` / `ENTERED_2`)

**1차 진입 (돌파)**

| # | 조건 | 초안 |
|---|------|------|
| E1 | 기준봉 고점 돌파 | 현재가(또는 당일 종가 확인 모드) > `ref_high` |
| E2 | 대안 | 전일 고점 돌파 (`entry_mode=prev_high`) — 설정 택1 또는 OR |
| E3 | 시간·슬롯 | `ymgp_trade_start`~`end`, `ymgp_max_slots`, 일일매수·현금예비 |
| E4 | 과열 컷 | 등락 ≥ `ymgp_max_change_pct` 이면 금지 |

금액: `ymgp_buy_amount_1` (소액).

**2차 진입 (눌림 재매수)**

| # | 조건 | 초안 |
|---|------|------|
| A1 | 1차 보유 중 | `ENTERED_1` |
| A2 | 눌림 지지 | 현재가가 **MA20** 또는 **기준봉 시가(`ref_open`)** 근처(±`pullback_tol_pct`)에서 지지 |
| A3 | 재돌파/반등 | 지지 후 단기 고점 재돌파 또는 양봉 확인 (노이즈 완화) |
| A4 | 무효화 전 | 기준봉 저점·손절선 미이탈 |

금액: `ymgp_buy_amount_2`. 기존 `is_add_buy` 경로 재사용.

### 4.6 무효화 · 손절

| # | 조건 | 동작 |
|---|------|------|
| X1 | 기준봉 저점 이탈 | `ref_low` 하향 (HARD: 즉시 / SOFT: 연속 확인) → 전량 청산 → `STOPPED` |
| X2 | MA 종가 이탈 | **60일선 또는 112일선** 종가 이탈 (`stop_ma_mode`: `ma60` \| `ma112` \| `either`) |
| X3 | 고정손절 백업 | 매수가 − `ymgp_stop_loss_pct` |
| X4 | 재진입 락 | `STOPPED` 후 `reentry_lock_days` 동안 신규 금지. 해제 조건: **새 매집봉 + 박스권 재형성** (`READY`/`ARMED` 재진입만 허용) |

### 4.7 익절 (분할) — 구현 기준

분할익절 ON (`ymgp_enable_partial_tp`)일 때, 손절이 아닌 한 **현재가 ≥ 목표가**이면 해당 단계 매도.

| 단계 | 목표가 (가격 트리거) | 청산 수량 | 설정 키 |
|------|----------------------|-----------|---------|
| **T1** | 최근 박스권 고점 = 최근 `ymgp_box_days`일 중 **최고가** | 보유 × `ymgp_tp1_pct_of_pos` (기본 0.35) | 박스 일수와 연동 |
| **T2** | **MA224** (224일 종가 단순이평) | 남은 보유 × `ymgp_tp2_pct_of_pos` (기본 0.35) | — |
| **T3** | **MA448** | **잔량 전량** | 비중 키 없음 |
| **T4** | (트레일) 고점 수익률 ≥ `ymgp_trailing_start_pct` 후, 고점 대비 `ymgp_trailing_pct` 하락 | 잔량 | 공통 트레일 경로 |

**판정 규칙**

1. 포지션의 `ymgp_tp_stage`로 다음 목표를 고른다 (0→T1, 1→T2, 2→T3).  
2. `현재가 >= 목표가`이면 해당 수량 시장가 매도.  
3. 부분 매도 후 stage +1. T3 또는 잔량 0이면 종료.  
4. 목표가 계산 불가면(일봉/MA 부족) 그 단계는 스킵·대기.  
5. 손절(기준봉 저 · 손절 MA · 고정%)이 익절보다 **우선**.

**예시** (보유 100주, tp1=0.35, tp2=0.35)

- 박스고점 터치 → 35주 매도 (잔 65)  
- MA224 터치 → 65×0.35 ≈ 22주 매도 (잔 43)  
- MA448 터치 → 43주 전량  

부분 매도 후 `MANAGING` 유지. 전량 종료 시 `DONE`.

## 5. 예시 로직 (제품 수락 기준)

문서에 제시된 시나리오를 **수락 테스트**로 고정한다.

1. 120/240/480(또는 설정 3선) **역배열** → `FILTERED`
2. 최근 10~20일 **박스권** → `READY`
3. 거래량 **2배 이상** 양봉 + 종가 **MA20 위** → `ARMED`, 기준봉 저장
4. 익일(또는 장중) **기준봉 고점 돌파** → 1차 매수 `ENTERED_1`
5. 손절: **기준봉 저점** 또는 **MA60 이탈** → `STOPPED` + 재진입 락
6. 익절: 직전 저항 → **MA224** → (선택) MA448

→ “멈추고 다시 드는 칼자루”만 잡는 구조임을 로그·검증 UI에서 단계별로 증명 가능해야 한다.

## 8. 개발 로드맵

### Phase 0 — 관측 (매수 OFF) ✅ 개발 착수 가능

- `ymgp_condition_names` 통과분 + 일봉 단계 판정 **로그만**
- 대시보드/검증에 `stage` 표시 (매수 버튼 없음)
- 성공: 실장 3~5일, “사고 싶은 역매공파 자리”가 `ARMED`에 들어오는지 육안 검증
- **금지**: 전종목 MA 전수 스캔

### Phase 1 — 1차 진입만 + 단순 손절

1. `evaluate_gate_pack("yeokmaegongpa")`  
2. `ARMED` + 기준봉 고점 돌파 시 `strategy=ymgp` 신호  
3. 슬롯·금액·시간 준수, `strategy_key=ymgp` 저장  
4. 청산: 기준봉 저점 또는 MA60 이탈 + 고정손절  
5. **재진입 락** 필수  
6. 회귀: `use_ymgp=False` 동일

### Phase 2 — 2차 눌림 + 분할 익절

- MA20/`ref_open` 눌림 추가매수 (`is_add_buy`)  
- T1 저항 / T2 MA224 / T3 MA448 부분 매도  
- 검증 UI: 단계·기준봉·익절 단계 체크리스트

### Phase 3 — 공구리·볼린저 옵션 · UI

- G3 볼린저/대체 기준선  
- 대시보드 토글·조건식 피커·금액 1/2  
- 장세 게이트에 `ymgp` 명시 포함  
- (선택) 당일 리플레이

### Phase 4 — 운영 튜닝

- MA 기간·박스·거래량 배수 A/B  
- 성과 집계(승률·평균보유·MDD) — 모니터링 PRD와 연계 가능

## 9. 기존 구현과의 접점 · 제약

### 9.1 재사용

- 멀티게이트 / `allows_strategy_new_buy` / 전략 슬롯  
- 피라미딩 추가매수 스캔  
- `StopLossManager` HARD/SOFT + 전략 분기 (`breakout` 분기 옆에 `ymgp`)  
- 조건식 피커 UI (`breakout_condition_names` 복제)  
- 차트/지표: `core/main.py` 볼린저·이평 계산 경로 참고

### 9.2 제약

| 제약 | 영향 | 대응 |
|------|------|------|
| REST rate limit | 장기 MA·박스 계산 비용 | **유니버스=조건식**, 일봉은 소수만 |
| 스캔 ~60초 | 돌파 순간 놓침 | 조건식+관심 `ARMED`만 분봉/현재가 폴링 |
| 부분 매도 | 키움 주문·잔량 동기화 | 기존 분할매도/수량 부족 가드 재사용 (`sell_qty` 테스트 참고) |
| 이평 정의 | HTS vs 서버 SMA | **서버 SMA 종가**로 통일, HTS 조건식은 유니버스용만 |
| 오버나잇 | 역매공파는 중기 | **당일청산 강제 안 함** (상따와 반대) |

### 9.3 전략 우선순위 (제안)

```
sangtta > breakout > ymgp > legacy
```

같은 종목 이중 진입 금지. 이미 HOLDING이면 스킵.

### 9.4 시간대 (제안)

| 전략 | 신규매수 윈도우 |
|------|----------------|
| sangtta | 09:05 ~ 11:00 |
| breakout | 11:00 ~ 14:30 (기존 확정) |
| ymgp | **09:30 ~ 14:30** (돌파·눌림 모두; 장초 과열은 `max_change_pct`로 컷) |
| legacy | 기존 |

## 부록 A. 과매도 돌파(`breakout`)와의 한 장 비교

| | 과매도 돌파 | 역매공파 |
