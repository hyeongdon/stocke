분석 화면 종목 상세에 **주봉 차트(위)와 일봉 차트(아래)를 함께** 보여주고, 각 차트에 RSI(14)·Williams %R(93) 보조지표 영역과 **RSI 과매도 진입 / Williams 매수** 신호 마커를 표시한다. 지표 기준값은 RWM 밥그릇 전략 파라미터를 그대로 읽어, 전략이 보는 신호와 화면에 보이는 신호를 일치시킨다.

## 3. 지표 · 신호 정의

### 3.1 주봉 리샘플

```text
주 단위      : ISO 주 (월~금). 연휴 주는 있는 거래일만 묶음
open        : 그 주 첫 거래일 시가
high / low  : 그 주 최고가 / 최저가
close       : 그 주 마지막 거래일 종가
volume      : 그 주 거래량 합계
timestamp   : 그 주 마지막 거래일
partial     : 오늘이 그 주 마지막 거래일이 아니고 장 마감 전이면 이번 주 = true (진행 중 주봉)
```

진행 중 주봉도 **차트에는 그린다** (현재 상황 확인용). 단 그 봉에서 나온 신호는 확정 아님 → 잠정 표시 (§4.2).

### 3.2 지표

| 지표 | 정의 | 파라미터 출처 |
|---|---|---|
| MA | 단순이평. 일봉 10/20/60/120일, **주봉 10/20/60/120주** (§9 D3) | 고정 |
| RSI | Wilder RSI(14), `rwm_bowl.wilder_rsi_series` | `rsi_period` |
| Williams %R | `(HH_n − close) / (HH_n − LL_n) × −100`, `rwm_bowl.williams_r_series` | **`w_period` = 93** (§9 D1) |

파라미터는 `utils/rwm_bowl.DEFAULT_PARAMS` 에서 읽는다. RWM 설정을 바꾸면 분석 화면도 같이 바뀐다.

### 3.3 신호

| 코드 | 이름 | 조건 | 파라미터 |
|---|---|---|---|
| `RSI_OS` | RSI 과매도 진입 | `RSI[i−1] > th AND RSI[i] ≤ th` (30 이하로 **처음 들어간 봉만**, 30 아래 체류 중 반복 표시 안 함) | 주봉 `rsi_os_weekly`(30), 일봉 `rsi_os_daily`(30) |
| `WR_BUY` | Williams 매수 | `%R[i−1] ≤ w_os < %R[i]` AND 직전 연속 `%R ≤ w_os` 봉 수 ≥ `w_min_bottom_bars` | `w_os`(−80), `w_min_bottom_bars`(2). `rwm_bowl.williams_turns` 재사용 |

- 주봉·일봉 각각 독립 판정 (주봉 신호는 주봉 지표로, 일봉 신호는 일봉 지표로).
- 표시 구간 밖(워밍업 구간) 신호는 응답에서 제외.
- RWM 밥그릇의 W 판정은 "일봉 과매도 이후" 조건이 붙지만, 분석 화면은 **조건 없이 모든 %R 반전**을 표시한다 (참고용).

## 4. 화면 상세

### 4.1 구성

| 요소 | 내용 |
|---|---|
| 배치 | 상세 패널 "가격 블록" 아래에 **주봉 차트 → 일봉 차트** 순서로 위아래 (§9 D4) |
| 캔버스 | 차트당 1개, 높이 약 400px = 가격 55% · RSI 22% · %R 23% |
| 가격 영역 | 캔들 + MA 4개 + 범례 + 신호 마커 |
| RSI 영역 | 0~100 고정 축, 30·70 점선, 30 이하 구간 음영 |
| %R 영역 | −100~0 고정 축, −20·−80 점선, −80 이하 구간 음영 |
| x 라벨 | 주봉 `YY.MM`, 일봉 `MM-DD` (처음·중간·끝) |
| 상태줄 | 기간 · 봉 수 · 최근 신호(종류·날짜) · 현재 RSI / %R · 경고(봉 부족 등) |
| 툴팁 | 마우스 위치 봉: 날짜, OHLC, 거래량, MA, RSI, %R, 해당 봉 신호 |
| 상세 지표 | 기존 MA10/20/60/120 칸 옆에 `주봉 RSI` · `주봉 %R` · `일봉 RSI` · `일봉 %R` 현재값 |
| 로딩 | 주봉·일봉 **독립 로딩** — 한쪽 실패해도 다른 쪽 표시 |

### 4.2 마커

| 신호 | 가격 영역 | 보조 영역 | 색 |
|---|---|---|---|
| `RSI_OS` | 캔들 저가 아래 ● | RSI 영역 해당 봉 ● | 보라 `#a78bfa` |
| `WR_BUY` | 캔들 저가 아래 ▲ (RSI 마커와 겹치면 한 칸 아래) | %R 영역 해당 봉 ▲ | 초록 `#34d399` |
| 잠정 (`partial`) | 속 빈 마커 + "잠정" 툴팁 | 동일 | 동일 |

색은 CSS 변수(`--sig-rsi`, `--sig-wr`)로 두어 다크/라이트 테마에 맞춘다.

### 4.3 코드 구조

`renderAnalysisChart` 를 분리해 주봉·일봉 캔버스가 공유한다.

```text
loadAnalysisCharts(code)          # 1W · 1D 병렬 호출
  └ renderChart(canvasId, payload)
       ├ layoutPanes(W, H)         # 가격 / RSI / %R 영역 좌표
       ├ drawPricePane(...)        # 캔들 · MA · 범례 (기존 로직 이동)
       ├ drawOscPane(..., 'rsi')   # 기준선 · 음영 · 라인
       ├ drawOscPane(..., 'wr')
       ├ drawSignalMarkers(...)
       └ bindTooltip(canvas, payload)
```

## 5. API

### 5.1 요청

`GET /fundamentals/{stock_code}/chart?interval=1W&bars=104`

| interval | 별칭 | 기본 bars | 범위 |
|---|---|---|---|
| `1W` (신규) | `W`, `WEEK`, `WEEKLY` | 104 | 26~260 |
| `1D` | 기존 | 120 | 30~200 |
| `5M` / `15M` | 기존 | — | 변경 없음 |

### 5.2 응답 (기존 필드 유지 + 추가)

```json
{
  "stock_code": "005930",
  "interval": "1W",
  "bars": [
    {
      "timestamp": "2026-08-29", "open": 0, "high": 0, "low": 0, "close": 0, "volume": 0,
      "ma10": 0, "ma20": 0, "ma60": 0, "ma120": 0,
      "rsi": 28.4, "wr": -85.1, "partial": false
    }
  ],
  "display_bars": 104,
  "ma_latest": { "ma10": 0, "ma20": 0, "ma60": 0, "ma120": 0 },
  "signals": [
    { "idx": 87, "date": "2026-08-29", "type": "WR_BUY", "value": -72.3, "partial": false },
    { "idx": 80, "date": "2026-07-11", "type": "RSI_OS", "value": 28.4, "partial": false }
  ],
  "indicator_latest": { "rsi": 41.2, "wr": -35.0 },
  "params": { "rsi_period": 14, "rsi_os": 30, "wr_period": 93, "wr_os": -80, "wr_min_bottom": 2 },
  "source_daily_bars": 1100,
  "warning": ""
}
```

- `idx` 는 `bars` 배열 기준 (표시 구간).
- `warning`: 워밍업 부족 시 `"상장 기간 부족 — MA120주·%R 일부 구간 미표시"` 등.
- 주봉·일봉은 같은 일봉 캐시(`code:1D`)를 공유해 키움 API 호출을 늘리지 않는다.

## 6. 데이터 확보 (먼저 확인)

| 차트 | 표시 | 워밍업 | 필요 일봉 |
|---|---|---|---|
| 일봉 | 120일 | MA120 = 120일 (%R 93 포함) | 약 250봉 — **현재 방식으로 충분** |
| 주봉 | 104주 | MA120주 = 120주 (%R 93주 포함) | 약 224주 ≈ **1,100봉 (4년 반)** |

현재 일봉 조회는 단건(연속 조회 없음) + `fetch_bars` 상한 400 → 주봉 요건 미충족 가능성이 크다.

**단계**

1. `ka10081` 단건 응답이 실제 몇 봉인지 측정 (대형주·신규상장 각 1종목).
2. 부족하면 `get_stock_chart_data` 에 일봉 연속 조회(`cont-yn`/`next-key`) 추가 — 같은 파일의 기존 연속 조회 패턴 재사용. `max_bars` 도달 시 중단, 페이지 상한 설정.
3. 그래도 부족하거나 호출 수가 과하면 `ka10082` 주봉 TR 신규 연동 (주봉 직접 수신, 리샘플 생략).
4. 일봉 캐시 TTL 은 기존 `_daily_chart_cache_ttl` 유지. 1,100봉 캐시는 주봉·일봉 두 차트가 공유.

## 8. 수락 기준

**지표**
- [ ] 주봉 OHLCV 가 HTS 주봉과 일치 (연휴 주 포함)
- [ ] 주봉·일봉 RSI(14) 가 HTS 값과 일치 (허용 오차 1.0)
- [ ] 주봉·일봉 %R(93) 이 HTS 값과 일치 (허용 오차 1.0)
- [ ] MA10/20/60/120 (일·주) 가 HTS 값과 일치

**신호**
- [ ] RSI 35 → 28 → 25 → 32 → 29 → `RSI_OS` 2회 (28, 29 봉)
- [ ] %R −85, −90 (2봉) → −70 → `WR_BUY` 1회 (−70 봉)
- [ ] %R −85 (1봉) → −70 → 신호 없음 (`w_min_bottom_bars` 2)
- [ ] 진행 중 주봉에서 나온 신호 → `partial: true`, 속 빈 마커
- [ ] `rwm_bowl.DEFAULT_PARAMS` 의 `w_period` 변경 시 응답 `params.wr_period` 와 신호가 따라 바뀜

**화면**
- [ ] 상세 패널에 주봉(위)·일봉(아래) 두 차트, 각 가격 / RSI / %R 3분할
- [ ] 주봉 MA10/20/60/120주, 일봉 MA10/20/60/120일
- [ ] 마커가 해당 봉 x 위치에 정확히 표시, RSI·W 동시 신호 시 겹치지 않음
- [ ] 호버 툴팁에 날짜·OHLC·RSI·%R·신호
- [ ] 주봉 API 실패 시 일봉 차트는 정상 표시 (반대도 동일)
- [ ] 신규 상장 종목: 봉 부족 경고, 있는 구간만 표시, 오류 없음
- [ ] 창 크기 변경 시 두 차트 모두 다시 그림
- [ ] 재무 마트에 없는 종목(`renderDetailFallback`)도 같은 2단 차트

**비기능**
- [ ] 상세 선택 → 두 차트 표시 ≤ 3초 (캐시 미스, 연속 조회 포함)
- [ ] 같은 종목 재선택 시 키움 API 추가 호출 없음 (캐시)
- [ ] 기존 분봉(`5M`/`15M`) 응답·검증 화면 동작 불변
