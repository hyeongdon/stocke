# 과매도 돌파전략 — 키움 HTS 조건식 초안

> 대상 전략: `strategy_key=breakout` / `gate_pack=oversold_breakout`  
> 목적: **5분봉 RSI 과매도→회복 구간 종목만 유니버스로 공급**  
> 원칙: 과매도 이력은 HTS 조건식이 담당하고, 실제 돌파는 프로그램이 **5분봉**으로 판정한다.

---

## 1. 권장 조건식 이름

```text
돌파
```

(또는 `BREAKOUT_RSI10_5M_18_28`)

이 조건식 **1개만** `breakout_condition_names`에 등록한다.

- API 비용 때문에 RSI 기간별·시장별 조건식을 여러 개 동시에 등록하지 않는다.
- `screener_condition_names`, `sangtta_condition_names`에는 등록하지 않는다.
- 조건식 결과를 거래대금 TopN이나 다른 전략 후보와 합치지 않는다.

---

## 2. 확정 핵심 조건 (운영값)

| # | 조건 | 권장값 | 필수 |
|---|------|--------|------|
| O1 | 주기 | **5분봉** | 필수 |
| O2 | RSI 기간 | **RSI(10)** | 필수 |
| O3 | 편입 | RSI가 **18 → 28** 구간으로 회복(상향) | 필수 |
| O4 | 현재 거래 가능 종목 | 거래정지·관리·정리매매 제외 | 필수 |
| O5 | 상품/종목 유형 | ETF·ETN·스팩·우선주 제외 | 필수 |
| O6 | 유동성 하한 | 현재가·거래대금 하한 | 선택(권장) |

핵심은 **일봉 RSI**가 아니라 **5분봉 RSI(10)이 과매도(≈18)에서 회복(≈28)으로 올라오는 종목**이다.

---

## 3. HTS 조건검색기 입력 방향

```text
주기: 5분
RSI 기간: 10
비교/발생: RSI 18 이하에서 28 방향으로 상향 (HTS 표현에 맞게)
(+ 제외) 관리/정리매매/거래정지/ETF/ETN/스팩/우선주
```

HTS 버전에 따라 `돌파`, `상향 돌파`, `구간 진입` 등 메뉴명이 다를 수 있다.  
의미만 **RSI(10) 18→28 회복**이면 된다.

---

## 4. 조건식에 넣지 않는 항목 (프로그램)

| 항목 | 담당 |
|------|------|
| 직전 5분봉 고가 / 최근 N봉 고가 | 프로그램 |
| 레벨 상향 돌파 판정 | 프로그램 |
| 5분봉 거래량 배수 | 프로그램 |
| 등락률 과열 컷 | 프로그램 |
| 전략 시간대·슬롯·매수 금액 | 프로그램 |
| 구조 이탈 HARD/SOFT 청산 | 프로그램 |

---

## 5. 프로그램 게이트 (요약)

```
유니버스 = breakout_condition_names 조건식 통과
차트 = 5분봉 (ka10080)
레벨 = prev_high(직전 5분 고가) | n_day_high(최근 N봉 고가, N=breakout_n_day)
거래량 = 현재 5분봉 거래량 ≥ 직전 N봉 평균 × breakout_vol_mult
과열 = 당일 등락 ≥ breakout_max_change_pct 이면 금지
```

---

## 6. 후보 수 운영 기준

- 조건식 결과가 평소 **5~20종목**이면 적정
- 20종목 초과가 반복되면 유동성 하한 강화
- 0~2종목이 반복되면 RSI 상한(28) 완화 또는 lookback 확대
