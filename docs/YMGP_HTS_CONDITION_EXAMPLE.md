# 역매공파 HTS 조건식 기준 (유니버스)

> 대상 전략: `strategy_key=ymgp` / `gate_pack=yeokmaegongpa`  
> 서버는 **조건식 통과 종목만** 일봉으로 단계(FILTERED→READY→ARMED)를 재판정합니다.  
> 전종목 MA 전수 스캔은 하지 않습니다 (API 비용).

---

## 1. 조건식이 맡는 일 vs 서버가 맡는 일

| 구분 | 조건식(HTS) | 서버(`ymgp_engine`) |
|------|-------------|---------------------|
| 유니버스 축소 | ✅ 필수 | — |
| 역배열·횡보 후보 | ✅ 권장 | ✅ 재확인 |
| 매집봉·공구리·돌파 | 선택(대략) | ✅ 확정 판정 |
| 1·2차 매수 / 손절 / 분할익절 | — | ✅ |

조건식은 **“관심 풀”** 이고, 실제 매수는 서버 단계가 `ARMED` + 기준봉 고점 돌파일 때만 나갑니다.

대시보드 **역매공파 → 종목 선정**에 등록:

## 3. HTS 조건식 설계 기준 (권장)

키움 HTS 표현은 버전마다 다르므로 **의도**만 고정합니다. 아래를 최대한 가깝게 구성하세요.

### 필수에 가까운 필터

| # | 의도 | 예시 표현 방향 |
|---|------|----------------|
| U1 | **장기 역배열** | 주가이평 120 < 240 < 480 (또는 60<112<224 — **서버 설정 MA와 맞출 것**) |
| U2 | **급락 이력** | 최근 60거래일 고점 대비 −20% 이상 하락 후 현재는 횡보 구간 |
| U3 | **유동성** | 최근 거래량/거래대금 하한 (너무 죽은 종목 제외) |
| U4 | **종목 제외** | ETF·ETN·스팩·우선주·관리/투자주의/정리매매 제외 |

### 있으면 좋은 필터 (노이즈↓)

| # | 의도 | 예시 |
|---|------|------|
| U5 | 박스·바닥 | 최근 10~20일 고저폭이 과도하지 않음 |
| U6 | 거래량 조짐 | 최근 수일 평균 거래량 > 박스 구간 평균 |
| U7 | 시총/가격 | 운영 선호 하한·상한 |

### 넣지 말 것 (서버가 함)

- “매집봉 정확히 2배 양봉 + 종가>중간값”을 조건식만으로 강제하지 않아도 됨 → 서버 `accum_vol_mult` 등으로 확정
- 장중 고점 돌파 순간 포착 → 서버 스캐너

## 4. 서버 설정과 맞추기

대시보드 **역매공파** 카드:

| 설정 | 기본 | 조건식과 관계 |
|------|------|----------------|
| 역배열 MA | 120 / 240 / 480 | **U1과 동일 기간** 권장 |
| 박스 일수·폭 | 15일 / 12% | U5와 대략 일치 · **T1 익절 목표가(박스 고점)** 에도 사용 |
| 급락 lookback·% | 60일 / −20% | U2와 일치 |
| 매집 거래량 배수 | 2.0 | 서버 확정 |
| 손절 MA | ma60 | 조건식 불필요 |
| 분할익절 | T1 박스고점 → T2 MA224 → T3 MA448 | **서버만** (조건식 불필요). 비중은 대시보드 |
| 매수 시간 | 09:30~14:30 | — |

조건식 MA와 서버 MA가 다르면 “조건식엔 들어왔는데 FILTERED도 안 됨”(NONE)이 자주 납니다.

## 4.1 운영 피드백 (2026-07-27)

당일 조건식 편입 피크 6종목 · 전원 `FILTERED`/`NONE` · READY 0.

| 관찰 | 의미 | 조건식 조치 |
|------|------|-------------|
| 동일 종목이 하루 종일 FILTERED | **역배열만** 통과한 “이른” 후보 | **U2 급락 이력 + U5 박스폭**을 조건식에 추가 권장 |
| 맵스리얼티1 → `NONE`(역배열 아님) | 조건식 MA ≠ 서버 120/240/480 가능 | **U1을 서버와 동일 기간으로 맞춤** |
| READY/ARMED 0 | 바닥·매집 전 단계 | 매집봉/공구리/돌파는 조건식에 넣지 말 것(서버 담당) |

권장 조정 순서:

1. HTS `역매공파` 조건식의 이평을 **120 < 240 < 480**으로 서버와 일치  
2. “최근 60일 고점 대비 −20% 이상” (또는 유사) **급락 이력** 추가  
3. “최근 10~20일 고저폭이 과도하지 않음” **박스/횡보** 완화 필터 추가  
4. 다음 장부터 로그 `📈 [YMGP] 단계수치 …` 로 박스폭·급락%·MA근접을 확인 후 미세조정  

조건식을 ARMED 수준으로 조이면 후보가 사라져 서버 학습이 안 됩니다. **FILTERED→READY 직전 풀**을 목표로 두세요.

---

## 5. 운영 체크리스트

1. HTS에서 위 기준으로 조건식 생성 → 이름 저장  
2. 대시보드 역매공파 ON + 조건식 피커 선택 + 설정 저장  
3. **역매공파 후보** 조회로 `READY`/`ARMED`가 뜨는지 확인 (Phase 0)  
4. 소액·슬롯 1로 1차 돌파만 켜고 관측 후, 2차 눌림·분할익절 토글 사용

| | 과매도 돌파 | 역매공파 |
