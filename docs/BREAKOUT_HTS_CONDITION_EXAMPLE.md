# 5분봉 수급 돌파 — 키움 HTS 조건식 (유니버스)

> 대상 전략: `strategy_key=breakout`  
> 기준 시나리오: 파세코(`037070`) 2026-07-24 5분봉 · [`PRD_BREAKOUT_5M_VOLUME.md`](PRD_BREAKOUT_5M_VOLUME.md)  
> **확정 방향 (2026-07-25)**: 유니버스 = **RSI 상향 전환 종목** / 매수 = **프로그램 파세코형 강한 이평·수급 돌파**  
> 구 문서: `OVERSOLD_BREAKOUT_HTS_CONDITION_EXAMPLE.md` (RSI 18→28) → 본 문서로 교체

---

## 0. 역할 (확정)

```
조건식(유니버스)  →  5분 RSI가 35를 상향 돌파하며 살아나는 종목만 후보
프로그램(매수)    →  그 후보 중 “강한 이평·레벨 돌파”(장대+거래량+종가돌파)만 매수
```

**RSI 전환 시점 ≠ 매수 시점.**  
조건식 편입 직후가 아니라, 이후(또는 같은 봉에서) 파세코형 게이트가 통과할 때 산다.

---

## 1. 권장 조건식 이름

```text
돌파
```

- `breakout_condition_names`에 **이 조건식만** 등록
- `screener` / `sangtta` / `ymgp` 와 **합치지 않음**

---

## 2. 확정 조건식 (HTS 실구성)

### 2.1 논리식

```text
G and J and P and (S or T or R) and Q and U
```

### 2.2 항목 정의

| 기호 | 조건 (화면 기준) | 역할 |
|------|------------------|------|
| **S** | `[5분] 4봉전 RSI(10) 35 이하` | 직전 짧은 구간에 과매도 이력 |
| **T** | `[5분] 2봉전 RSI(10) 35 이하` | 〃 |
| **R** | `[5분] 3봉전 RSI(10) 35 이하` | 〃 |
| **Q** | `[5분] 1봉전 RSI(10) 35 상향돌파` | **전환 트리거** (방금 35를 상향) |
| **U** | `[일] 0봉전 RSI(10) 1봉 연속 상승` | 일봉도 살아 있는 종목만 |
| **G, J, P** | (화면 상단 — 제외·유동성 등) | 기본 필터. **내용 확정 후 아래에 기입** |

`(S or T or R) and Q` 의미:

- 2~4봉 전에 RSI ≤ 35였고  
- **1봉 전에** RSI가 35를 **상향 돌파**했다  

→ “과매도에서 막 돌아선” 5분 타이밍의 종목만 유니버스.

### 2.3 G / J / P (기입란)

운영 전 아래를 채워 문서와 HTS를 동기화한다.

| 기호 | 내용 (예) | 확정값 |
|------|-----------|--------|
| G | 관리·정리·정지·ETF·스팩·우선주 제외 등 | _(기입)_ |
| J | 거래대금·현재가 하한 등 | _(기입)_ |
| P | 기타(시장/감리 등) | _(기입)_ |

## 3. 조건식에 넣지 않는 것 → 프로그램 매수

| 항목 | 담당 | 파세코 12:30 |
|------|------|--------------|
| N봉 고가 **종가** 돌파 | 프로그램 | 6,090 → 6,270 |
| 장대 몸통 ≥ **+2%** | 프로그램 | +3.64% |
| 범위 ≥ 평균×**3** | 프로그램 | ≈4.3× |
| 거래량 ≥ 평균×**3** | 프로그램 | ≈4.7×+ |
| 종가 ≥ **MA20** (강한 이평 돌파) | 프로그램 | ✅ |
| **MA20 상향 돌파 + 거래량 동반** | 프로그램 | 힘스 09:30: C>MA20 · V+253% |
| (선택) 종가 ≥ MA120 또는 MA120 상향 | 프로그램 | 돌파봉이 이평대에서 출발 |
| 과열컷·시간·슬롯·손절 | 프로그램 | |

게이트 요약:

```
유니버스 통과 종목만
확인봉(완성 5분) AND:
  close > max(prior N highs)
  body% >= 2.0
  range >= avg_range(12)*3
  # 핵심: MA20 상향 돌파 + 거래량
  close[i-1] <= MA20[i-1] and close[i] > MA20[i]
  volume[i]  >= avg_vol(N) * 3.0
  (optional) RSI >= 50
  day_change < max_pct
```

MA20은 **전일 포함 연속 5분봉** SMA(종가,20). 장초(09:30) 힘스형 신호에 필요.

## 4. 타이밍 주의

| 단계 | 누가 | 언제 |
|------|------|------|
| 편입 | 조건식 | Q(1봉전 35 상향) 성립 시 |
| 매수 | 프로그램 | **그 이후** 파세코형 장대·이평 돌파 봉 |

파세코는 RSI가 먼저 살아나고(40→50대), **12:30에야** 강한 돌파.  
조건식만으로 매수하면 압축 구간에서 자주 물린다 → **분리 유지가 핵심**.

### lookback이 짧은 점

지금 `(S|T|R)`는 **2~4봉 전**만 봄.  
저점이 더 예전에 찍히고 한참 횡보 후 돌파하는 종목은 편입에서 빠질 수 있음.  
편입이 너무 적으면: 5~8봉전 ≤35 OR 추가, 또는 lookback을 넓힌다.

## 5. 운영 눈금

| 장중 편입 수 | 조치 |
|--------------|------|
| **10~40** | 적정 |
| 과다 | G/J/P(유동성) 강화 |
| 과소 | `(S|T|R)` lookback 확대, 또는 35→40 |

일봉 U(RSI 상승)는 하락 일봉과 싸우는 가짜를 줄이는 데 유리 — 유지 권장.
